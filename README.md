# Wireless Network Simulation

Wireless network simulation project using Cisco Packet Tracer.

## Features
- Static Routing
- RIPv2
- Wireless Network
- Access Point Configuration
- Server Configuration
- Multiple LAN Networks
- Subnetting

## Devices
- Router
- Switch
- Access Point
- Server
- PC
- Laptop
- Smartphone

## Tools
- Cisco Packet Tracer
